# 焊缝跟踪教学演示

一个无需安装依赖、可直接在浏览器打开的教学项目，用来讲解结构光视觉焊缝跟踪的基本流程：识别焊缝特征、观察工件偏差、理解机器人路径修正。

## 功能

- 拼接焊、圆弧焊、搭接焊、直角焊四种示意工件
- 调整横向/纵向偏移和工件旋转
- 显示名义焊缝、修正轨迹和激光扫描线示意
- 附跟踪流程说明和教学伪代码
- 纯静态网页，无需构建工具或外部服务

## 接头几何约定

- **拼接焊**：两块板处于同一平面，边缘相对形成接缝；示意路径沿接缝走向。
- **圆弧焊**：表示沿弧形接缝运动的路径示例，它描述路径形状，不是基本接头类别。
- **搭接焊**：两板有实际重叠，示意焊缝放在上板搭接边缘（趾端）处。
- **直角焊**：按参考样式表现为 T 形接头角焊缝，一块立板垂直放在底板上，焊缝沿两板交界线延伸；上视图中的扫描线横跨该焊缝。

激光扫描线在独立的上视图中显示，并横跨焊缝；主视图用于看工件接头和机器人路径。截面图用于说明传感器轮廓上的特征位置。

## 运行

直接用浏览器打开 `index.html`，或使用任意静态文件服务器托管本目录。

## 课堂建议

1. 先选择接头，让学生指出传感器可能识别的边缘、交点或中心特征。
2. 调整偏移和旋转，让学生先预测焊缝位置，再观察演示。
3. 讨论感知、坐标转换、路径修正和安全停止对应的程序阶段。
4. 对比四种接头的特征点和路径形式，填写实验记录。

## 范围与限制

这是概念演示，不是焊缝图像处理算法，也不与 ABB1410、机器人控制器、英莱相机或焊机通信。页面中的工件、扫描线和路径均为示意；调整的偏移值不代表真实标定精度或控制性能。真实设备接入需要设备接口、跟踪启停方式、工具/工件坐标系、坐标变换和安全联锁资料，并由设备负责人审核与验证。

几何定义参考 [Miller Welds 焊接接头类型资料](https://www.millerwelds.com/-/media/miller-electric/files/pdf/articles/jointypes.pdf) 和 [AWS A2.4 焊接符号图表](https://app.aws.org/mwf/attachments/64/225364/AWSWeldSymbolchart.pdf)。
